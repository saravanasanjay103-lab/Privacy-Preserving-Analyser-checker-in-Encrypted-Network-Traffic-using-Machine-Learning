Why this matters

  1. Timing jitterRandom delay added between packets raises inter-arrival std deviation, which the model weighs heavily for beacon-like traffic.
  2. Packet paddingExtra bytes per packet push average packet size toward normal ranges, hiding the tiny fixed-size beacons botnets use.
  3. Rate throttlingSlowing transmission drops the byte rate, the single strongest signal separating C2 beacons from browsing traffic in this dataset.

Limitation. This model only sees flow metadata, so it has no way to tell a padded/throttled attack from genuinely light traffic - a real adversary with enough patience can lower detection this way. That is a known limitation of metadata-only IDS, not a bug.
